# Student Attendance Management System

A beginner-friendly front-end attendance tracker built with HTML, CSS, and JavaScript.

## Files
- `index.html` — project home page and module navigation
- `admin.html` — add/delete students, mark attendance, summary counts, CSV export
- `user.html` — look up a student's attendance summary by ID
- `style.css` — responsive layout using CSS Grid and Flexbox
- `script.js` — attendance logic and Local Storage persistence

## Run locally
Open `index.html` in a modern browser. No server or dependencies are required.

## Notes
This is a learning/demo project. Local Storage is browser-specific and is not suitable for sensitive real student records or multi-user production deployments. The admin page is not protected by real authentication.
